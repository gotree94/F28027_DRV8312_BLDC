# 04. 하드웨어 이해

F28027과 DRV8312의 인터페이스를 정확히 이해하고, 실제 배선을 설계합니다.

## 4.1 TMS320F28027 핵심 사양

| 항목 | 값 |
|----|----|
| CPU | C28x, 60 MHz, 32비트 고정소수점 |
| Flash / RAM | 64 KB / 12 KB |
| PWM | ePWM1~4 (모듈당 A/B 채널 → 최대 8개 출력), ePWM1A/2A/3A는 HRPWM |
| ADC | 12비트, 최대 12채널(ADCINA0~7, ADCINB0~3), 0~3.3V |
| 아날로그 비교기 | COMP1~3 (내부 10비트 DAC 리퍼런스) → BEMF 영점검출에 활용 가능 |
| eQEP | 1채널(인코더) — HDD 모터엔 없지만 일반 모터용 |
| eCAP | 1채널 — 주파수/펄스 측정 |
| 통신 | SCI(UART) 1ch, SPI 1ch, I2C 1ch, CAN 1ch |
| GPIO | 최대 22개 (MUX된 핀) |
| 전원 | 3.3V 단일 공급(내부 LDO는 5V 필요 시), I/O 3.3V |
| 패키지 | 38핀 TSSOP (F28027PT = 48핀 QFP도 존재) |

### 주요 핀 그룹 (38핀 TSSOP 기준 참고값, 데이터시트 SPRS523 확인 필수)

- 전원: VDD(3.3V), VDDIO(3.3V), VDDA(ADC용 3.3V), VSSA, VREGENZ
- 오실레이터: X1/X2(크리스탈), XCLKIN
- ADC: ADCINA0~7, ADCINB0~3
- PWM: EPWM1A/1B~EPWM4A/4B (GPIO mux)
- JTAG: TMS/TCK/TDO/TDI/TRST
- SCI: SCIRXDA/SCITXDA

> 핀맵과 GPIO mux 테이블은 반드시 **SPRS523**(데이터시트) 또는
> **SPRUGE9**(TRM)에서 확인해야 합니다. 보드 설계 시 핀 재사용(mux) 충돌을 검사하세요.

## 4.2 DRV8312 핵심 사양

| 항목 | 값 |
|----|----|
| 전원 | PVDD(모터, 10.8~50V), GVDD/VDDA(12V 로직), GND |
| 출력 | 3상 (OUT A/B/C), 하프브리지 3개, FET 통합 |
| 전류 | 3.5A 연속 / 6.5A peak (DRV8312), DRV8332는 더 큼 |
| 제어 인터페이스 | **3xPWM** (IN A/B/C), PWM 주파수 최대 500 kHz |
| 보호 | 언더볼티지, 과온, 과전류(cycle-by-cycle), 단락, 부트스트랩 UVP |
| FAULT/OTW | 개방 드레인 출력, 외부 풀업 필요 |
| GATE | 신호는 0~3.3V 로직에서 직접 구동 가능 (레벨 시프트 내장) |
| 부트스트랩 | 핀마다 BOOTRST/CP1/CP2 콘덴서 필요 (47nF 등) |
| 전류센싱 | 외부 하이/로우사이드 션트 → MCU ADC로 |

> **DRV8312는 "3xPWM" 방식**입니다. 즉, 상하단 데드타임을 DRV8312가 내부적으로
> 생성하므로 MCU는 3개의 PWM 출력(IN_A, IN_B, IN_C)만 주면 됩니다.
> F28027의 ePWM1A/2A/3A 3채널이면 충분합니다.

### DRV8312 필수 주변부품 (데이터시트 SLES256 참고)
- GVDD 레귤레이터용 콘덴서/인덕터
- 각 부트스트랩 핀에 47nF(전형) 콘덴서
- PVDD 바이패스 콘덴서 + 전해 콘덴서
- VDD/GVDD 바이패스 콘덴서
- OUT단에 스너버 불필요(내장)
- FAULT/OTW 풀업 저항(MCU 3.3V 풀업)

## 4.3 F28027 ↔ DRV8312 배선 설계 (3xPWM)

| 기능 | F28027 핀(예시) | DRV8312 핀 | 비고 |
|----|----|----|----|
| 상 A PWM | EPWM1A (GPIO0) | IN_A | 3.3V 로직 직접 연결 |
| 상 B PWM | EPWM2A (GPIO2) | IN_B |  |
| 상 C PWM | EPWM3A (GPIO4) | IN_C |  |
| 전류 센싱 | ADCINA0/1/2 | IPA/IPB/IPC (션트 증폭 후) | 션트 3개 or 2개 |
| 버스전압 | ADCINB0 | PVDD 분압 | 10:1 분압 + 필터 |
| FAULT | GPIO1 | FAULT (풀업) | active-low, 인터럽트 |
| GATE(래치 리셋) | GPIO3 | GATE/Reset 입력 | high=run, low=disable |
| (선택) OTW | GPIO5 | OTW | 과온 경고 |
| 공통 GND | GND | GND | 반드시 연결 |

> 위 핀 번호는 **예시**입니다. 실제로는 DRV8312-C2-KIT 보드의 핀맵(F28035 기준)이나
> 자작 보드 스키매틱에 맞춰 결정합니다. `controlSUITE\DRV8312-C2-KIT_v128\Hardware\`
> 스키매틱을 참고하세요.

### 3xPWM 구동 논리
| IN_A | IN_B | IN_C | 통전상 |
|----|----|----|----|
| PWM | 0 | 0 | A+ / B-,C- 없음 → A상 전류 |
| 0 | PWM | 0 | B+ |
| 0 | 0 | PWM | C+ |
| (이후 6-step 조합 반복) |  |  |  |

실제 6-step 통전 테이블은 [07. BLDC 제어 알고리즘](07_BLDC_제어_알고리즘.md) 참고.

## 4.4 DRV8312 보호/래치 동작

- **GATE 리셋** : DRV8312는 오류(FAULT) 시 각 하프브리지를 래치로 끕니다.
  `GATE` 핀(또는 RSTA/B/C)을 low로 하면 래치가 리셋됩니다.
  → MCU GPIO로 제어하거나 수동 스위치 사용.
- **FAULT** : 오류 시 low. MCU 인터럽트로 걸어 **모터 전원 차단 / PWM 정지** 처리.
- **PVDD UVLO** : PVDD가 10.8V 미만이면 구동 불가. **HDD 모터 12V 구동 시 반드시
  12V 안정 공급**.
- **부트스트랩 UVP** : PWM 주파수 < 약 10 kHz 또는 듀티가 낮으면 하이사이드 구동에
  필요한 부트스트랩 전압이 부족해질 수 있음. → **PWM 주파수 15~20 kHz 사용 권장**.

## 4.5 하드웨어 구성 방법 (2가지 경로)

### 경로 A: DRV8312-C2-KIT 보드 사용
- DRV8312 보드(베이스보드) + F28027 controlCARD(DIMM100) 조합
- TMDSDOCK28027 키트의 controlCARD가 그대로 장착 가능
- 단, 키트의 기본 예제가 F28035 기준이라 **핀맵/헤더를 F28027용으로 재정의** 필요
- 장점: 검증된 회로, 션트/보호 완비 / 단점: 키트 구매 필요, F28035 예제 마이그레이션

### 경로 B: 자작 보드
- F28027 최소 시스템(크리스탈, 전원, JTAG) + DRV8312 주변회로를 직접 설계
- 이 프로젝트 docs의 회로/소스를 근간으로 구현
- 장점: 최종 목적에 최적화 / 단점: 초기 디버깅 난이도 높음

> 이 문서에서는 **경로 A를 우선 권장**합니다. 개발환경이 잡히고 알고리즘이 검증된
> 후, 필요 시 경로 B(자작 보드)로 이전하는 것이 안전합니다.

## 4.6 LaunchPad 사용 시 (LAUNCHXL-F28027)

- LaunchPad는 DIMM100 controlCARD가 아니므로 DRV8312-C2-KIT 베이스보드에 꽂을 수
  없습니다.
- LaunchPad 헤더에서 **EPWM1A/2A/3A, ADC, GPIO, GND**를 점퍼 배선으로 DRV8312
  모듈(또는 자작 드라이버)에 연결합니다.
- LaunchPad 보드에 **저전압 드라이버 단을 직접 장착**하거나, BOOSTXL 형태의 3상
  게이트 드라이버와 조합하는 것도 방법입니다.

## 4.7 전원 설계

| 도메인 | 값 | 소스 |
|----|----|----|
| MCU | 3.3V | LaunchPad 온보드 또는 별도 LDO (AMS1117 등) |
| DRV8312 로직 | 12V (GVDD/VDDA) | 별도 12V 또는 PVDD→벅 (키트는 VR1 벅 사용) |
| 모터 | 12V (PVDD) | 가변 DC 전원 (전류 제한 필수) |
| 공통 GND | 0V | 전 도메인 단일 접지 |

> **안전** : 모든 보드 테스트는 전류 제한(1A부터)이 되는 가변 전원으로 시작하고,
> 전원 순서는 1) MCU 3.3V → 2) DRV8312 12V → 3) PVDD 순으로 인가합니다.
