# 03. 개발환경 구축

F28027(C2000 Piccolo) 개발환경을 순서대로 구축합니다. Windows 기준으로 작성했습니다.

## 3.1 필요 소프트웨어 목록

| 소프트웨어 | 역할 | 다운로드 |
|----|----|----|
| Code Composer Studio (CCS) | 통합 개발환경(편집/빌드/디버그) | TI.com → `CCSTUDIO` |
| controlSUITE | DRV8312-C2-KIT 소스, device support, IQmath, DMC 라이브러리 | TI.com → `CONTROLSUITE` |
| TI C2000 컴파일러 | C28x용 컴파일러 툴체인 | CCS 안에서 설치 또는 별도 |
| XDS100 USB 드라이버 | USB-JTAG 에뮬레이터 드라이버 | CCS에 포함 (LaunchPad 내장 XDS100) |
| (선택) UniFlash | 독립형 플래시 툴 | TI.com → `UNIFLASH` |

## 3.2 Code Composer Studio 설치

1. TI.com에서 **CCS(CCSTUDIO)** 최신 버전을 다운로드합니다.
   - 레거시 controlSUITE 프로젝트는 최신 CCS에서도 **Import**가 가능하지만, 일부
     오래된 프로젝트는 컴파일러 버전 때문에 경고가 뜰 수 있습니다.
2. 설치 중 **"Components to install"** 화면에서 반드시 다음을 선택:
   - **C2000 32-bit MCUs** (타깃 지원)
   - **TI C2000 compiler tools** (컴파일러; 최신 또는 v6.4.x)
   - **XDS100 emulators** (USB 디버거 드라이버)
3. 설치 경로는 기본값(`C:\ti\ccs...`)을 권장합니다. controlSUITE도 `C:\ti`에
   설치하면 두 경로가 깔끔하게 정리됩니다.

### 주의: 컴파일러 버전
- controlSUITE의 레거시 예제 중 일부는 예전 컴파일러(v6.x)로 작성되었습니다.
- 빌드 오류 시 **Project Properties → Build → Compiler** 에서 사용할 컴파일러 버전을
  v6.4.x 또는 v16.x(신형 C2000 v16.9+)로 전환합니다.
- F28027 코드는 최신 컴파일러(v16.x~v20.x)에서도 정상 빌드됩니다. 우리 자체
  프로젝트는 **최신 컴파일러**를 사용합니다.

## 3.3 controlSUITE 설치

1. TI.com에서 **CONTROLSUITE** 툴 페이지 → 최신 버전 다운로드
   (약 수백 MB, 압축 또는 설치형).
2. 기본 경로(`C:\ti\controlSUITE`)에 설치/압축해제합니다.
3. 설치 후 아래 경로가 존재하는지 확인합니다.
   ```
   C:\ti\controlSUITE\development_kits\DRV8312-C2-KIT_v128\
   C:\ti\controlSUITE\device_support\f2802x\
   C:\ti\controlSUITE\libs\math\IQmath\
   C:\ti\controlSUITE\libs\app_libs\motor_control\
   ```
4. (권장) controlSUITE에서 필요한 예제를 우리 프로젝트 폴더로 복사해 두면
   원본을 보존한 채 수정할 수 있습니다.

> controlSUITE는 레거시 제품이라 TI 홈페이지에서 찾기 어려울 수 있습니다.
> 검색창에 `CONTROLSUITE`를 입력해 툴 페이지를 직접 열거나, C2000Ware의
> "ControlSUITE to C2000Ware Transition Guide"를 참고하세요.

## 3.4 드라이버 설치

- XDS100v2 USB 드라이버는 CCS 설치 시 자동 설치됩니다.
- LaunchPad(LAUNCHXL-F28027)를 사용하면 보드에 **XDS110**(신형) 또는 **XDS100v2**
  가 내장되어 USB 케이블만으로 디버깅할 수 있습니다.
- **TMDSDOCK28027**(Experimenter Kit)의 controlCARD도 온보드 XDS100v2 포함입니다.
- 연결 후 장치 관리자에서 "XDS110 Debug Probe" 또는 "XDS100v2"가 보이면 정상입니다.

## 3.5 하드웨어 개발 도구 (선택)

| 도구 | 용도 |
|----|----|
| 디지털 오실로스코프 (2ch 이상) | PWM 파형, BEMF, 전류 파형 확인 (필수에 가까움) |
| 차동 프로브/아이솔레이션 | DRV8312 고전압부(12V~24V) 측정 시 |
| LCR 미터 | HDD 모터 상 저항/인덕턴스 측정 |
| 가변 DC 전원 (0~24V, 1~3A) | 모터 구동 전원(PVDD)과 전류 제한 |
| 멀티미터 | 전압/단락/연속성 확인 |

## 3.6 개발환경 검증 (첫 빌드)

제일 먼저 빌드 체인과 디버거가 정상인지 아래 순서로 확인합니다.

1. CCS 실행 → **Workspace** 폴더 지정 (예: `C:\ti\workspace`)
2. **Project → Import CCS Projects** → 제어판에서
   `C:\ti\controlSUITE\development_kits\DRV8312-C2-KIT_v128\BLDC_Sensored` 선택
   - (F28035 기준 프로젝트이므로 첫 검증은 보드/controlCARD가 F28035일 때만
     그대로 빌드·플래시 가능. F28027로 돌리려면 docs/05의 마이그레이션 절차 참고)
3. **Project → Build All** 로 빌드 → `.out` 파일 생성 확인
4. **Run → Debug** → XDS와 타깃 연결 → 플래시 로드 확인
5. (**중요**) 이 단계에서는 **모터 전원을 인가하지 말고**, 펌웨어가 디버거로
   실행되는 것만 확인합니다.

> "hello world" 대신, docs/05에서 이 프로젝트를 위한 **F28027 전용 빈 프로젝트**를
> 처음부터 만들어 보는 것이 이 프로젝트에는 더 적합합니다. 아래 단계로 진행합니다.

## 3.7 첫 F28027 전용 프로젝트 준비 (요약)

1. CCS에서 **New Project** 선택
2. Target: `TMS320F28027` (또는 `TMS320F28027PT` 48핀 QFP 등 실제 패키지 기준)
3. 프로젝트 타입: Empty (ASM+C), 링커 cmd는 추후 F28027용으로 교체
4. include 경로에 추가 예정:
   - `C:\ti\controlSUITE\device_support\f2802x\v230\...` (디바이스 헤더)
   - `C:\ti\controlSUITE\libs\math\IQmath\v160\...` (IQmath, 필요 시)
5. 첫 코드: GPIO 토글 → [06. 주변장치 설정](06_주변장치_설정.md) 참고

> 상세한 프로젝트 생성 절차는 [05. 첫 프로젝트 생성](05_첫_프로젝트_생성.md)에서
> 다룹니다.
