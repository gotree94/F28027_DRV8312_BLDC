# 01. 프로젝트 개요

## 1.1 목표

- **최종 목표** : NIDEC HDD 스핀들용 3상 BLDC 모터를 F28027이 계산한 PWM 신호로
  DRV8312를 통해 구동하고, **목표 회전수(RPM)로 정밀하게 속도 제어**한다.
- **중간 목표** :
  1. TI 레퍼런스(`DRV8312-C2-KIT`) 소스를 파악하여 근간으로 삼는다.
  2. 개발환경(CCS + controlSUITE)을 구축하고 빌드/플래시/디버그가 가능하게 한다.
  3. F28027의 주변장치(ePWM, ADC, GPIO, eQEP, 아날로그 비교기)를 직접 설정한다.
  4. 센서리스 트래피조이달 제어로 모터를 기동·가속한다.
  5. 속도 PI 폐루프로 목표 RPM을 추종하게 한다.

## 1.2 시스템 구성

```
┌──────────────────────────────┐      ┌─────────────────────┐
│  PC (CCS, USB/XDS100)        │      │  NIDEC HDD BLDC 모터 │
└──────────────┬───────────────┘      │  (3상, 센서리스)     │
               │ JTAG/SCI              └─────────┬───────────┘
┌──────────────▼───────────────┐      ┌──────────▼───────────┐
│  TMS320F28027 (60 MHz)       │ PWM  │  DRV8312            │
│  - ePWM1~4 (3상 PWM 6ch)     ├─────►│  - 3상 하프브리지    │
│  - ADC (전류/전압/역기전력)   │◄─────┤  - FAULT/GATE, 래치  │
│  - eQEP (인코더, 선택)       │ ADC  │  - 과전류·과열 보호   │
│  - 아날로그 비교기 (BEMF)    │      └─────────┬───────────┘
│  - SCI (모니터링)            │      ┌─────────▼───────────┐
└──────────────┬───────────────┘      │  24V/12V 전원        │
               │ 3.3V / 5V            └─────────────────────┘
```

## 1.3 하드웨어 제약과 고려사항

| 항목 | 내용 |
|----|----|
| F28027 공급전압 | 3.3V 단일 공급 (내부 LDO는 5V 필요). I/O는 3.3V TTL |
| DRV8312 공급 | GVDD/VDDA = 12V, PVDD = 모터 전압(최소 10.8V, 최대 50V) |
| 모터 정격 | HDD 스핀들 모터: 12V, 수백 mA~수 A, 저인덕턴스(수십~수백 µH) |
| PWM 주파수 | DRV8312 부트스트랩 유지 위해 **10 kHz 이상 권장** (kit는 20 kHz 사용) |
| 센서 유무 | HDD 스핀들 모터는 대부분 **홀센서 없음** → 센서리스(BEMF) 필요 |
| 고극수 | 8~12극(4~6극쌍) → 전기각 주파수는 기계 rpm의 4~6배 |

## 1.4 왜 "센서리스 트래피조이달"인가?

- HDD 스핀들 모터는 대부분 홀센서가 없어 역기전력(Back-EMF) 기반의
  센서리스 제어가 필수적입니다.
- 트래피조이달(120° 통전) 방식은 6-step commutation으로 단순하고,
  저전압·저비용 애플리케이션(HDD 스핀들 등)에서 가장 널리 쓰입니다.
- FOC(벡터제어)보다 구현이 단순해 **첫 구동까지의 시간이 짧고** 디버깅이 쉽습니다.
- F28027은 InstaSPIN(하드웨어 가속 센서리스 FOC)을 지원하지 않으므로(지원은
  F28027F), 전통적인 방식이 정석입니다.

## 1.5 추후 확장 방향 (선택)

- FOC(Field Oriented Control) 구현으로 토크 리플 감소
- UART/SCI로 실시간 모니터링 및 목표 속도 명령
- CAN 버스 제어
- 전류 루프 추가로 토크 제어
- eQEP 인코더(또는 홀센서) 기반 정밀 속도/위치 제어
