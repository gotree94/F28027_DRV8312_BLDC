# 10. 최종 목표와 확장

프로젝트의 최종 검증 기준, 산출물, 그리고 향후 확장 방향을 정리합니다.

## 10.1 최종 목표 (수락 기준)

> **NIDEC HDD BLDC 모터를 F28027 + DRV8312로 구동하여, 목표 회전수(RPM)를
> ±5% 이내 정밀도로 추종하고, 기동~정지 전체 과정이 안정적으로 반복 동작한다.**

### 세부 수락 기준
| 항목 | 기준 |
|----|----|
| 기동 | 정렬 → 오픈 루프 → 폐루프 전환 성공 (성공률 100% 반복 시험) |
| 정상 운전 | 목표 RPM ±5% 이내 (부하 변동 시) |
| 속도 범위 | 0 ~ 정격 (예: 5400 RPM) |
| 보호 | 과전류/FAULT 시 3상 PWM 0% + 상태 표시, 자동 복구 또는 안전 정지 |
| 제어 주기 | ePWM 인터럽트 기반, 실시간성 유지 |
| 문서/소스 | 이 저장소의 문서와 매칭되는 소스 |

## 10.2 최종 검증 절차

1. **반복 기동 시험**: 정지→정격 속도 가속→감속→정지 50회, 실패 0회.
2. **부하 변동 시험**: 손/지그로 부하를 걸고 속도 유지 확인 (단, FDB 베어링 보호).
3. **전압 변동 시험**: PVDD 11~13V 범위에서 속도 유지 확인.
4. **온도 시험**: 30분 연속 운전 시 드라이버/모터 온도 상승 확인.
5. **보호 시험**: 의도적으로 과전류 상황(스탤 등)을 만들어 FAULT 동작 확인.
6. **장시간 시험**: 24h 연속 운전 (스핀들 모터 수명·발열 확인).

## 10.4 확장 방향 (선택)

| 확장 | 내용 | 이점 |
|----|----|----|
| **FOC** | 센서리스 FOC(슬라이딩 모드 관측기 등) | 토크 리플 감소, 저속 성능 |
| **전류 루프** | 션트 전류 기반 토크 제어 | 부하 정밀 제어 |
| **SCI 명령** | PC GUI 또는 CLI로 목표 속도 설정 | 튜닝 자동화 |
| **CAN** | 다중 드라이브/원격 제어 | 산업 응용 |
| **eQEP** | 인코더 장착 시 정밀 위치/속도 | 고정밀 응용 |
| **C2000Ware** | 최신 디바이스 지원 + driverlib | 유지보수성 |
| **UART 로깅** | 운전 데이터 기록 | 디버깅/분석 |
