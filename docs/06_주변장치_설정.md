# 06. 주변장치 설정

BLDC 구동에 필요한 F28027 주변장치(ePWM, ADC, GPIO, 아날로그 비교기, 인터럽트)의
설정 방법을 기술합니다. 모든 코드는 실제 F2802x 레지스터 기준입니다.

> TRM은 **SPRUGE9**(TMS320F2802x Technical Reference Manual)입니다.
> 레지스터 필드명은 controlSUITE `f2802x\v230`의 `F2802x_*` 헤더와 일치합니다.

## 6.1 ePWM (3상 PWM, 3xPWM 방식)

### 핵심 개념
- F28027은 ePWM1~4 (각 A/B) 존재. BLDC 3xPWM에는 **ePWM1A/2A/3A** 사용.
- **3xPWM 방식**이므로 상단(U-phase) PWM만 생성하면 DRV8312가 내부 데드타임 처리.
  하단은 별도 출력 불필요.
- PWM 주파수: **20 kHz** 권장 (부트스트랩 UVP 회피, 가청음 회피).

### 20 kHz 기준 클럭 계산
- SYSCLK = 60 MHz, TBCLK = SYSCLK / 1 = 60 MHz
- TBPRD = 60000000 / 20000 = **3000** → ePWM 주기 20 kHz, 분해능 60MHz/3000 = 20 kHz
- 듀티 100% = CMPA = 3000

### 레지스터 설정 예시 (ePWM1)

```c
// ---- ePWM1 초기화 (UP-DOWN 카운트, PWM 1:1, active-high) ----
void InitEPWM1(void) {
    EALLOW;
    SysCtrlRegs.PCLKCR0.bit.TBCLKSYNC = 0;   // 동기화 잠금
    EDIS;

    EPwm1Regs.TBSTS.all = 0;
    EPwm1Regs.TBPHS.all = 0;
    EPwm1Regs.TBCTR = 0;
    EPwm1Regs.CMPA.all = 0;                  // 듀티 0%
    EPwm1Regs.CMPB.all = 0;

    // TBCTL: Free-run, UP-DOWN, TBCLK=SYSCLK
    EPwm1Regs.TBCTL.bit.CTRMODE = TB_COUNT_UP;
    EPwm1Regs.TBCTL.bit.PHSEN   = TB_DISABLE;
    EPwm1Regs.TBCTL.bit.HSPCLKDIV = TB_DIV1;
    EPwm1Regs.TBCTL.bit.CLKDIV    = TB_DIV1;
    EPwm1Regs.TBCTL.bit.SYNCOSEL  = TB_CTR_ZERO;

    EPwm1Regs.TBPRD = 3000;                  // 20 kHz

    // CMPA up/down mode, active-high (EPWM1A), EPWM1B는 high(=1) 고정 아님 → 3xPWM은 A만 사용
    EPwm1Regs.CMPCTL.bit.SHDWAMODE = CC_SHADOW;
    EPwm1Regs.CMPCTL.bit.SHDWBMODE = CC_SHADOW;
    EPwm1Regs.CMPCTL.bit.LOADAMODE = CC_CTR_ZERO;
    EPwm1Regs.AQCTLA.bit.CAU = AQ_SET;
    EPwm1Regs.AQCTLA.bit.CAD = AQ_CLEAR;

    // 3xPWM: EPWM1B(상단 보조)는 미사용 → EPWM1A만 출력
    EPwm1Regs.DBCTL.bit.OUT_MODE = 0;        // 데드밴드 미사용(드라이버 내장)

    EALLOW;
    SysCtrlRegs.PCLKCR0.bit.TBCLKSYNC = 1;   // 동기화 해제
    EDIS;
}
```

### 듀티 변경 함수
```c
// duty: 0~3000 (0% ~ 100%)
void SetEPWM1Duty(Uint16 duty) {
    EPwm1Regs.CMPA.half.CMPA = duty;
}
```

> ePWM2/ePWM3는 ePWM1과 동일하게 초기화하되 **위상(TBPHS)을 0으로** 두고,
> 6-step 통전 시 상별 듀티를 조절하는 방식이 아니라, 아래처럼 **매 스텝 통전 조합을
> 직접 제어**합니다 (docs/07 참고).

## 6.2 BLDC 6-step을 위한 ePWM 출력 제어

트래피조이달 방식에서는 "PWM 출력 + 방향(0/1)"을 핀 단위로 결정합니다.
핀 하나마다 출력을 0(로우) / 1(하이) / PWM(듀티) 세 상태로 제어해야 하므로,
GPIO로 출력 상태를 바꾸기보다 **AQ(액션) 규칙을 재설정**하거나,
가장 간단하게는 **ePWM 출력을 GPIO로 대체**하는 방법이 있습니다.

권장 구현 (간단한 방법):
- 각 상에 대해 `IN_A` 신호를 하나의 GPIO(예: GPIO0)로 멀티플렉스해서
  - PWM일 때: GPIO mux를 ePWM1A로
  - 로우(0)일 때: GPIO mux를 GPIO 출력 → 0
  - 하이(1)일 때: GPIO mux를 GPIO 출력 → 1
- 이 방식을 쓰면 펌웨어만으로 6-step이 쉽게 구현됩니다.
  - 핀 mux 전환에 오버헤드가 있지만 60 MHz에서 충분히 빠릅니다.

```c
// 상 A 핀 mux 전환 예시
void PhaseA_PWM(void)  { GpioCtrlRegs.GPAMUX1.bit.GPIO0 = 1; }  // EPWM1A
void PhaseA_Low(void)  {
    GpioCtrlRegs.GPAMUX1.bit.GPIO0 = 0;
    GpioDataRegs.GPACLEAR.bit.GPIO0 = 1;   // 0 출력
}
void PhaseA_High(void) {
    GpioCtrlRegs.GPAMUX1.bit.GPIO0 = 0;
    GpioDataRegs.GPASET.bit.GPIO0 = 1;     // 1 출력
}
```

> 정확한 GPIO 인덱스(mux 값)는 SPRS523의 핀 멀티플렉스 테이블을 확인하세요.

## 6.3 ADC (전류 / 버스전압 / BEMF 감지용)

### 설정 포인트
- 12비트, 0~3.3V, 변환시간 ~216ns/채널
- 소프트웨어 트리거로 시작해도 되지만, 실시간 제어에서는 **ePWM 트리거 동기화** 사용
- 정밀도 향상을 위해 채널별로 **오버샘플링 + 평균** 사용 권장

### 전류 센싱 회로 (션트 → 증폭)
- DRV8312 보드의 로우사이드 션트 → OPA(키트는 OPA365A 사용) → MCU ADC
- 션트 전류 → 전압 변환식: `V_adc = I_phase * R_shunt * Gain`
- ADC에서 읽은 값을 다시 전류로: `I = (V_adc - offset) / (R_shunt * Gain)`
- 바이어스(중간점)는 1.65V 등으로 설정해 양/음 전류 모두 측정 가능

### ADC 소프트웨어 트리거 예시
```c
void InitADC(void) {
    AdcRegs.ADCCTL1.bit.ADCPWDN  = 1;   // ADC 전원
    AdcRegs.ADCCTL1.bit.ADCENABLE = 1;
    DELAY_US(1000);                      // 전원 안정화
    AdcRegs.ADCCTL1.bit.ADCCLKPS = 4;   // 클럭 분주
    AdcRegs.ADCCTL2.bit.ADCNONOVERLAP = 1;
}

Uint16 ReadADC(volatile Uint16 ch) {
    AdcRegs.ADCSOC0CTL.bit.CHSEL = ch;           // 채널 선택
    AdcRegs.ADCSOC0CTL.bit.TRIGSEL = 0;          // 소프트웨어 트리거
    AdcRegs.ADCSOC0CTL.bit.ACQPS = 14;           // 샘플링 윈도우
    AdcRegs.ADCINTSOC1... // (선택) 트리거
    while(AdcRegs.ADCINTFLG.bit.ADCINT1 == 0){}  // 완료 대기
    AdcRegs.ADCINTFLGCLR.bit.ADCINT1 = 1;
    return AdcResult.ADCRESULT0;
}
```

> 실제 상세 레지스터 설정은 controlSUITE의 `F2802x_Adc.c` 예제를 복사해 사용하는
> 것을 권장합니다.

## 6.4 아날로그 비교기 (BEMF 영점검출, 센서리스용)

F28027은 3개의 아날로그 비교기(COMP1~3)와 내부 10비트 DAC 리퍼런스를 갖습니다.

- 용도: 각 상의 **역기전력(BEMF)이 중성점 전압과 교차하는 순간**을 검출
- 검출 결과로 6-step commutation 시점을 계산 (docs/07 상세)
- 비교기 출력은 인터럽트를 걸거나 ePWM에 연결 가능

### BEMF 측정 회로 구성 (전형)
- 모터 단자(U/V/W)를 저항 분압(예: 20kΩ / 10kΩ) → MCU ADC/comparator 입력
- 중성점(센터탭이 없는 모터면 가상 중성점 생성) 전압과 비교
- HDD 스핀들 모터는 대부분 **Y결선 + 센터탭 4핀** 또는 3핀입니다 (docs/08 확인)

### 비교기 설정 예시 (COMP1)
```c
EALLOW;
Comp1Regs.COMPCTL.bit.COMPDACEN = 1;   // DAC 활성
Comp1Regs.COMPCTL.bit.COMPSOURCE = 0;  // ADCINA0 (BEMF 입력)
Comp1Regs.DACVAL.bit.DACVAL = 2048;    // 10bit DAC: 중성점 기준값
EDIS;
// 비교기 출력 → GPIO 또는 인터럽트 라우팅 (XINT 등)
```

## 6.5 GPIO 설정

```c
void InitUserGPIO(void) {
    EALLOW;
    // 예: GPIO0 = EPWM1A (mux=1), GPIO2 = EPWM2A, GPIO4 = EPWM3A
    GpioCtrlRegs.GPAMUX1.bit.GPIO0 = 1;
    GpioCtrlRegs.GPAMUX1.bit.GPIO2 = 1;
    GpioCtrlRegs.GPAMUX1.bit.GPIO4 = 1;
    // 예: GPIO1 = FAULT 입력 (풀업), GPIO3 = GATE 출력
    GpioCtrlRegs.GPAMUX1.bit.GPIO1 = 0;
    GpioCtrlRegs.GPADIR.bit.GPIO1  = 0;        // input
    GpioCtrlRegs.GPAPUD.bit.GPIO1  = 0;        // 풀업 활성
    GpioCtrlRegs.GPAMUX1.bit.GPIO3 = 0;
    GpioCtrlRegs.GPADIR.bit.GPIO3  = 1;        // output
    GpioDataRegs.GPASET.bit.GPIO3 = 1;         // GATE = high (run)
    EDIS;
}
```

## 6.6 인터럽트

- **PIE** 기반 인터럽트를 사용합니다 (C28x 표준).
- F2802x 초기화: `InitPieCtrl()`, `IER=0`, `IFR=0`, `PieCtrlRegs.PIEIER1...` 설정,
  `InitPieVectTable()` 호출 → ISR 등록
- BLDC 제어 루프는 **ePWM 인터럽트**(예: EPWM1_INT, 매 PWM 주기 20 kHz)에서 수행
- FAULT 인터럽트는 **XINT** 또는 GPIO 폴링으로 처리

### 예: ePWM1 주기 인터럽트로 제어 루프 실행
```c
// InitPieVectTable 이후
PieVectTable.EPWM1_INT = &BLDC_ISR;
...
EPwm1Regs.ETSEL.bit.INTEN = 1;
EPwm1Regs.ETSEL.bit.INTSEL = ET_CTR_ZERO;   // 주기 끝마다
EPwm1Regs.ETPS.bit.INTPRD = ET_1ST;         // 1주기마다 1회
PieCtrlRegs.PIEIER3.bit.INTx1 = 1;          // EPWM1_INT = PIE 그룹3.1
IER |= M_INT3;
```

## 6.7 SCI (UART) — 실시간 모니터링/명령 (선택)

- 목표 속도 명령, 현재 속도, 전류, 온도 등을 시리얼로 주고받을 수 있게 하면
  튜닝(시운전)이 매우 편해집니다.
- F28027의 SCI는 GPIO28/29(GPIO28=SCIRXDA, GPIO29=SCITXDA) 등에 mux 가능.

```c
// 115200 baud, 8N1 예시 (60 MHz 기준)
SciaRegs.SCIHBAUD = 0x0000;
SciaRegs.SCILBAUD = 32;    // 60MHz / (32*16) ≈ 115200
SciaRegs.SCICCR.all = 0x0007;   // 8-bit, no parity, 1 stop
SciaRegs.SCICTL1.all = 0x0003;  // enable TX,RX
```

## 6.8 주변장치 검증 (모터 연결 전)

1. ePWM 출력에 오실로스코프 연결 → **20 kHz, 0% 듀티** 확인
2. 듀티를 50%로 올려 파형/주파수 확인 → 다시 0%
3. FAULT 핀이 high(정상)인지 확인
4. ADC로 PVDD 분압값을 읽어 실제 전압과 일치하는지 확인
5. SCI로 임의 문자열 전송 → PC에서 수신 확인

> **이 단계까지는 모터를 연결하지 않습니다.** 전원(PVDD 12V) 인가 여부와 상관없이
> 3상 PWM 파형이 0%로 유지되는지 확인합니다.
