# 09. 시운전과 튜닝

실제 모터를 구동하는 단계입니다. **반드시 안전 수칙을 먼저 읽고 진행**하세요.

## 9.1 안전 수칙 (반드시 준수)

1. **전원**: 가변 DC 전원 사용, **전류 제한을 0.5~1A부터 시작**하여 단계적으로 증가.
2. **배선**: 드라이브 회로는 전원이 꺼진 상태에서만 배선/분리. 극성 오배선 금지.
3. **절연**: PVDD(12V) 측에 접촉 시 감전 위험. 절연 프로브/글러브 권장.
4. **모터 고정**: 모터가 튀지 않도록 지그에 고정. 회전부 손/옷/케이블 주의.
5. **긴급 정지**: 메인 루프에 FAULT 확인, 전원 차단 스위치 준비.
6. **온도**: 모터/드라이버/션트 온도가 과도하게 오르지 않도록 확인.
7. **부팅 시 안전 상태**: MCU 리셋 시 **3상 PWM이 반드시 0%** 로 시작되도록 GPIO
   기본 상태 설정(드라이버 디스에이블로 시작).

## 9.2 시운전 절차 (레벨별)

### L1. 센싱 검증 (모터 미연결)
- 버스전압 ADC값이 실제 전압과 일치하는지 확인.
- 션트 전류가 0일 때 ADC 오프셋을 기록 (보정용).

### L2. 오픈 루프 기동 (모터 연결, 전류 제한 0.5A)
1. 듀티 10% → 정렬 200ms → 통전 스텝을 500ms 간격으로 수동 진행.
2. 모터가 "갇혀서 따라오는지(스텝 추종)" 확인. 갈짓자 운동이면 결선 순서 확인.
3. 정렬 + 램프로 1~2초 동안 저속(수십~백 RPM) 회전까지 시도.
4. 성공하면 오실로스코프로 3상 전압 파형, commutation 타이밍 확인.

### L3. BEMF 영점검출 (폐루프 전환)
1. 오픈 루프로 어느 정도 속도를 올린 뒤, 영점검출 인터럽트가 뜨는지 확인.
2. 영점검출 신호와 commutation 시점의 위상차를 오실로스코프로 확인.
3. 동기화 오차가 30°(전기각)에 가까우면 폐루프 전환 시도.
4. 폐루프 전환 직후 듀티를 낮춰 토크 스파이크 방지.

### L4. 속도 PI 폐루프
- eCAP으로 측정한 속도를 목표 속도와 비교 → PI 출력으로 듀티 조절.
- 목표 속도를 낮게(예: 1000 RPM) 시작해 서서히 올림.

### L5. 보호/모니터링
- FAULT, 과전류 리밋, SCI 모니터링을 켜고 정상 운전.

## 9.3 PI 속도 제어

### 제어 블록
```
목표 속도(RPM) ─→[오차]─→ PI ─→ 듀티(CMPA) ─→ ePWM → DRV8312 → 모터
                   ↑
         측정 속도(RPM) ←─ 속도계산(eCAP/commutation 주기)
```

### 이산 PI 구현 (고정소수점 또는 float)
```c
#define KP  0.5f      // 시운전 시작값
#define KI  0.01f
float Integral = 0.0f;

float SpeedPI(float ref, float meas) {
    float err = ref - meas;
    Integral += err;
    if (Integral > INTEG_MAX) Integral = INTEG_MAX;   // 안티와인드업
    if (Integral < -INTEG_MAX) Integral = -INTEG_MAX;
    return KP*err + KI*Integral;
}
```

### 튜닝 순서 (Ziegler-Nichols 응용)
1. **KI=0**으로 두고 **KP**를 서서히 증가 → 목표 속도에 가까워지도록.
2. KP 증가로 진동(오버슈트/링잉)이 생기면 KP를 약간 줄이고 **KI**를 추가.
3. KI 증가로 정상상태 오차가 줄어드는지 확인.
4. 최종적으로 부하 변동 시 속도가 ±5% 이내 유지되는지 확인.

> 듀티 출력은 **0~MAX_DUTY**로 클램프. PID 샘플링 주기는 commutation 주기나
> 고정 주기(예: 1kHz) 중 택1.

## 9.4 공통 문제와 대응

| 증상 | 원인/대응 |
|----|----|
| 모터가 웅웅거리며 안 돎 | 6-step 순서/극성 오류, 상 순서(U-V-W) 확인 |
| 기동 시 후퇴만 함 | 정렬이 부족(시간/듀티), 램프 시작 주파수 너무 낮음 |
| 고속에서 통전 실패(스탤) | 영점검출 필터 지연 → 위상 보정, BEMF 감쇠 |
| 과전류 FAULT | 듀티 과대, 션트 게인 부정합, commutation 타이밍 오류 |
| 부트스트랩 UVP | PWM 주파수 <10kHz, 듀티가 극단적으로 낮음 |
| 속도 리플 | 영점검출 필터, PI 게인 과대, 전류 리밋 |
| 발열 | PWM 주파수 과다, 스위칭 손실, 전류 과다 |
| 방향이 반대 | 스텝 테이블 역순 또는 결선 2선 교환 |
