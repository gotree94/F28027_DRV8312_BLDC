# 08. HDD 모터 특성화

대상 모터인 **NIDEC HDD 스핀들용 BLDC 모터**의 파라미터를 확인/측정하고, 제어
상수를 결정합니다.

## 8.1 HDD 스핀들 모터의 일반적 특성

| 항목 | 일반값 | 비고 |
|----|----|----|
| 상 수 | 3상 | U/V/W (Y결선, 센터탭 4핀 또는 3핀) |
| 정격 전압 | 12V | DRV8312 PVDD 최소 10.8V 이상 → **12V 적합** |
| 정격 속도 | 5400 / 7200 / 10000 RPM | 드라이브 세대별 |
| 극 수 | 8~12 (극쌍 4~6) | 세대·기종별 다름 |
| 상 저항 | 2~10 Ω (자석·모델 의존) | 매우 낮음 |
| 상 인덕턴스 | 수십~수백 µH | 매우 낮음 → PWM 리플 큼 |
| 기동 전류 | 수 A (peak) | 정격의 수 배 |
| 센서 | **대부분 없음(센서리스)** | 홀센서 내장 드라이브도 일부 존재 |
| 베어링 | 유체동압 베어링(FDB) | 축방향 저항 낮음, 외력에 약함 |

> **주의**: HDD 모터는 분해·파손품이 많고 제원표가 없습니다. **반드시 직접 측정**한
> 값을 기준으로 제어 상수를 정합니다.

## 8.2 모터 배선 식별 (핀 수/배선)

HDD 모터는 케이블 수에 따라 다음 중 하나입니다.

| 배선 | 구성 | 연결 |
|----|----|----|
| 4핀 | Y결선 + 센터탭(중성점) | U, V, W + Center. Center는 중성점 측정용으로 유용 |
| 3핀 | Y결선 (센터탭 미노출) | U, V, W. 가상 중성점 회로 필요 |
| 5핀 (드물게) | 3상 + 홀 2개 등 | 홀센서 존재 시 센서드 가능 |

### 배선 식별 절차 (멀티미터)
1. 상 간 저항 측정: U-V, V-W, W-U 가 모두 **동일한 값**이면 Y결선 가능성 높음
   (Y결선은 R_phase 상당값, Δ결선은 저항비가 다름).
2. 센터탭이 있으면 U-Center = V-Center = W-Center = **상저항/2 근사** 확인.
3. 상 저항은 작으므로(수 Ω) **4선식 측정 또는 전류 인가 방식** 권장.
4. 어느 두 선을 연결해도 전혀 저항이 안 보이면 **센서리 없는 드라이브**의 경우
   모터가 아닐 수 있으므로 재확인.

## 8.3 파라미터 측정 방법

### 8.3.1 상 저항 (Rs)
- **방법 A (4선식 멀티미터)**: 2Ω 범위, 두 단자에 전류 단자+전압 단자 동시 측정.
- **방법 B (정전류)**: 12V 전원에 직렬 저항(예: 10Ω)으로 100mA급 정전류 → 전압 강하
  ÷ 전류.
- Y결선 U-V 사이 측정값 = 2×Rs, U-Center = Rs.

### 8.3.2 상 인덕턴스 (Ls)
- LCR 미터: 1kHz에서 U-V 간 L을 측정 → Y결선이면 Ls = L(U-V)/2.
- LCR 미터가 없으면 **스텝 응답**으로 추정:
  - 직렬 저항 R + 모터 상에 계단 전압 인가 → 전류 상승 시간상수 τ = L/R
  - 오실로스코프로 전류 파형 기울기에서 τ 측정.

### 8.3.3 역기전력 상수 (Ke) — 수동 회전법
1. 모터를 손으로(또는 다른 모터로) **회전**시키면서 상 단자 사이의 AC 전압 측정.
2. 회전수(n)와 전기 주파수를 알면:
   - Ke [V/rad/s] = 측정 전압(Vpk) / 전기 각속도
3. 또는, 전압/주파수비(상전압 ÷ 전기주파수)로 BEMF 크기 예측.

### 8.3.4 극 수 (Pole pairs)
- **방법 A (수동 회전 + 오실로스코프)**: 모터를 한 바퀴 돌리면서 상전압이 몇 번
  진동하는지 카운트 → 극쌍 수 = 진동수/2.
- **방법 B (전기각 vs 기계각)**: 서보 모터로 강제 회전하며 측정.
- **방법 C (구동 후)** : 오픈 루프로 1 RPM 램프 후 commutation 주기로 역산.

> 극쌍 수는 **속도 계산**(docs/07)과 **영점검출 타이밍**에 직접 사용되므로 정확히
> 측정해야 합니다.

## 8.4 Nidec 모터 라벨 해석

Nidec HDD 모터는 로터 플레이트에 유사한 라벨이 찍혀 있습니다.
예: `Nidec  WDDA-...` 등. 라벨만으로 제원을 알 수 없는 경우가 많으므로,
**모델명은 참고만 하고 전기적 파라미터는 직접 측정**합니다.

## 8.5 제어 상수 결정 (측정값 → 설계값)

측정된 값을 아래 표에 채워 제어 상수를 결정합니다.

| 항목 | 기호 | 값(예) | 활용 |
|----|----|----|----|
| 상 저항 | Rs | 5 Ω | 전류 리밋, 듀티 초기값 |
| 상 인덕턴스 | Ls | 150 µH | PWM 리플, 전류 루프(추후) |
| 역기전력 상수 | Ke | 0.1 V/(rad/s) | BEMF 감지 기준값 |
| 극쌍 수 | P | 4 | 속도 계산 |
| 정격 전압 | V | 12V | PVDD |
| PWM 주파수 | fPWM | 20 kHz | ePWM TBPRD |
| 기동 듀티 | D_start | 20% | 정렬 단계 |
| 램프 기울기 | dω/dt | 500~2000 eHz/s | 오픈 루프 가속 |
| BEMF 감지 기준 | V_zc | 버스/2 근사 | 비교기 DAC값 |

### 주요 계산 예시 (예: P=4, 목표 5400 RPM)
- 기계 속도 5400 RPM → 90 rev/s → 전기 주파수 = 90 × 4 = **360 Hz**
- commutation 주기 = 1 / (360 × 6) = **463 µs**
- 20 kHz PWM 1주기 = 50 µs → 한 스텝당 약 9.3 PWM 주기
- 오픈 루프 램프에서 초기 전기 주파수 예: 5 Hz → 목표 360 Hz까지
  가속 시간 = (360-5)/1000 ≈ 0.36 s (기울기 1000 eHz/s 가정)

## 8.6 HDD 모터 구동의 특별 고려사항

1. **저인덕턴스** → PWM 리플 전류가 큼 → 듀티 제한, 션트 필터, (필요시) 스너버.
2. **고극수** → 전기 주파수가 기계 rpm의 4~6배 → 영점검출 타이밍이 짧음.
3. **FDB 베어링** → 축방향 힘/과도 기동 스트레스에 취약 → 부드러운 기동.
4. **플래터/스핀들 관성** → 가감속 여유. 급정지는 BEMF 서지 위험.
5. **센터탭 활용** → 센터탭이 있는 모터면 중성점 전압을 직접 읽어 영점검출 기준을
   정확히 잡을 수 있음 (가상 중성점 불필요).
6. **부하 없음(공회전) 구동 시** → 관성이 플래터 없으면 매우 낮음 → 오픈 루프
   램프가 빨라지므로 주의 (모터 단독 시험용 지그 고려).
