# 02. TI 레퍼런스 조사

이 문서는 이 프로젝트의 근간이 되는 **TI 공식 레퍼런스**를 조사한 결과입니다.
F28027(정확히는 동일 계열 Piccolo) + DRV8312 조합은 TI가 이미 키트로 출시했고,
**전체 소스가 오픈소스로 공개**되어 있습니다.

## 2.1 가장 중요한 레퍼런스: DRV8312-C2-KIT

**공식 이름** : `DRV8312-C2-KIT` — *Three Phase BLDC Motor Kit with DRV8312 and
Piccolo MCU*

- TI의 공식 중전압(Medium Voltage) 디지털 모터 제어(DMC) 평가 키트
- 구성 : DRV8312 3상 인버터 보드 + C2000 controlCARD(F28035 기본, **F28027 등
  DIMM100 controlCARD로 교체 가능**) + BLDC 모터 + 24V 전원
- 우리 구성(F28027 + DRV8312 + BLDC 모터)과 **거의 동일한 하드웨어 구조**이므로
  소스와 회로도를 그대로 참고할 수 있습니다.

### 소스 위치 (controlSUITE 설치 후)

```
C:\ti\controlSUITE\development_kits\DRV8312-C2-KIT_v128\
├── BLDC_Sensored\          # 홀센서 기반 센서드 BLDC (트래피조이달) CCS 프로젝트
├── BLDC_Sensorless\        # 센서리스 BLDC CCS 프로젝트 (있는 버전/없는 버전 확인 필요)
├── GUI_project\            # DRV8312GUIv5 와 연동되는 GUI 프로젝트
├── InstaSPIN...            # InstaSPIN-FOC/MOTION (F28027F 등 -F 장치 전용)
├── DRV8312GUIv5\           # PC용 GUI (시운전용)
├── Hardware\               # 스키매틱, 아트웍, BOM (Altium/PDF)
└── ... (HowToRunGuide 등 문서)
```

> **중요** : `BLDC_Sensored`는 독립 실행형 CCS 프로젝트로 GUI 없이 CCS에서 빌드 후
> 플래시하여 사용합니다. `GUI_project`는 PC GUI(DRV8312GUIv5)와 시리얼로 통신하며
> 동작합니다. (출처: TI E2E DRV8312-C2-KIT 질문 답변)

## 2.3 소프트웨어 다운로드

| 항목 | 경로/번호 | 비고 |
|----|----|----|
| **controlSUITE** | TI 홈페이지 `CONTROLSUITE` 툴 페이지 | 약 수백 MB. DRV8312-C2-KIT 소스 포함 |
| **Code Composer Studio** | TI `CCSTUDIO` 툴 페이지 | 최신 CCS는 레거시 프로젝트도 import 가능 |
| **C2000 Compiler (TI v16.x~v6.x)** | CCS 내에서 설치 | 레거시 예제는 v6.4 등으로 빌드 |
| IQmath | controlSUITE `libs\math\IQmath\v160\` | 고정소수점 수학 라이브러리 |
| DMC 라이브러리 | controlSUITE `libs\app_libs\motor_control\` | BLDC/FOC 모듈 소스 |

> **C2000Ware와의 관계** : TI는 최신 SDK를 C2000Ware로 이전했지만, DRV8312-C2-KIT
> 전용 프로젝트는 **controlSUITE에만** 존재합니다. controlSUITE는 레거시지만 계속
> 다운로드 가능하므로 반드시 설치합니다.

## 2.4 이 키트를 근간으로 우리 프로젝트에 적용하는 방법

우리 프로젝트는 "키트 소스를 그대로 돌리는 것"이 아니라 **그 소스를 이해하고
F28027 + NIDEC HDD 모터 조합에 맞게 재구성**하는 것입니다.

1. controlSUITE 설치 후 `BLDC_Sensored` 프로젝트를 import하여 **빌드/디버깅 환경부터
   익힌다** (키트 모터로 동작 확인).
2. 프로젝트의 `DSP2803x`(F28035) 의존 헤더/링커를 **F2802x** 계열로 교체한다.
   - `device_support\f2802x\v230\` 사용 (헤더 파일 구조가 2803x와 유사)
   - 링커 command file을 `28027_RAM_lnk.cmd` / `F28027.cmd`(FLASH) 로 변경
3. 핀맵을 DRV8312 보드 기준으로 재배선 (docs/04 참고).
4. 모터 파라미터를 Nidec HDD 모터 기준으로 변경 (docs/08).
5. 홀센서가 없는 HDD 모터이므로 **센서리스** 경로(또는 BEMF 방식)로 최종 구성.

## 2.5 참고할 다른 TI 레퍼런스

- **InstaSPIN-BLDC / MOTORWARE** : F28027F용. F28027(비-F)과는 하드웨어가 달라
  그대로 못 쓰지만, BEMF 영점검출(zero-cross) 알고리즘 개념 참고에 유용.
- **TIDM-THREEPHASE-BLDC-LC-INST** : F28069M + DRV8312 센서리스 FOC 레퍼런스 디자인.
  고급 단계에서 FOC 전환 시 참고.
- **SPRA701** (A Software Modularity Strategy for Digital Control Systems) :
  TI 모터제어 소스의 모듈 구조(빌드 레벨 방식)를 이해하는 입문 문서.
- **SPRA995** : 아날로그 제어 → C2000 디지털 제어 전환 가이드.

## 2.6 커뮤니티/포럼

- TI E2E C2000 포럼 (영어): `e2e.ti.com/support/microcontrollers/c2000...`
  - "DRV8312-C2-KIT: BLDC Sensored Code to Flash" 등 실제 사용 예 검색 가능
- 이 프로젝트는 controlSUITE 설치 후 로컬에서 모든 소스를 확보할 수 있으므로
  네트워크 의존도가 낮습니다.

## 2.7 결론

> **TI 레퍼런스 = DRV8312-C2-KIT + controlSUITE** 가 핵심입니다.
> F28027을 DIMM100 controlCARD로 사용하거나 자작 보드로 구성하더라도, 이 키트의
> 회로도·BOM·소스를 근간으로 삼아 프로젝트를 진행합니다.
