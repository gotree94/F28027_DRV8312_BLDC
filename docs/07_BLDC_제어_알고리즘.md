# 07. BLDC 제어 알고리즘

이 프로젝트의 핵심 제어 방식인 **120° 트래피조이달(6-step) 통전**과 **센서리스
(BEMF 영점검출)** 를 단계별로 설계합니다.

## 7.1 BLDC 모터 기본

- 3상 BLDC는 회전자(영구자석) 위치에 따라 두 상에만 전류를 흘려 토크를 만들고,
  위치가 바뀔 때마다 통전 조합을 바꿉니다 (commutation).
- 통전 조합을 60°(전기각)마다 바꾸면 360°에 6번, 즉 **6-step** 이 됩니다.
- 회전자 위치를 알려면: (a) 홀센서, (b) 역기전력(BEMF) 측정 → **센서리스**

## 7.2 6-step 통전 테이블

상 전류가 들어가는 상(+, PWM)과 나가는 상(-, 0V)의 조합은 총 6가지입니다.

| 스텝 | 전기각 | IN_A | IN_B | IN_C | 통전 (하이→로우) |
|----|----|----|----|----|----|
| 1 | 0~60°   | PWM | 0 | 0 | A+ → B- (C 오픈) |
| 2 | 60~120° | PWM | 0 | 0 | A+ → C- |
| 3 | 120~180°| 0   | PWM | 0 | B+ → C- |
| 4 | 180~240°| 0   | PWM | 0 | B+ → A- |
| 5 | 240~300°| 0   | 0 | PWM | C+ → A- |
| 6 | 300~360°| 0   | 0 | PWM | C+ → B- |

> 위 표는 **전류 방향 기준**입니다. 실제 DRV8312 3xPWM 입력(IN_A/B/C)은
> "high-side에 PWM, low-side는 자동 대칭" 방식이 아니라 **인가 전압 레벨**을 정합니다.
> 3xPWM에서는:
> - "+" : 해당 상 high-side ON (IN = PWM)
> - "-" : 해당 상 low-side ON (IN = 0)
> - 오픈 : 해당 상 high-side OFF, low-side OFF (IN = 0이지만 통전 없음,
>   → 실제로는 상하단 모두 OFF = High-Z. 3xPWM 드라이버에서 IN=0은 low-side만 ON
>   임을 주의. **오픈 상은 "High-Z"가 되어야** 하는데 3xPWM만으로는 어려우므로,
>   DRV8312는 IN=0 → low-side ON으로 동작 → 오픈 상에 역기전력이 클램프됩니다.
>   이 클램프가 BEMF 측정에 영향을 주므로 **저속 센서리스에서는 "제3상 PWM" 또는
>   BEMF 측정 구간(통전 오프 구간)에서 샘플링**하는 기법이 필요합니다.)

### 3xPWM과 6-step의 현실적 구현 (중요)
- DRV8312는 **3xPWM**(IN_A/B/C 각각 high-side PWM, low-side는 내부에서 반전·데드타임
  적용)이므로 IN=0이면 그 상의 **low-side만 ON**이 됩니다. 즉 "완전 오픈(High-Z)"
  상태를 만들 수 없습니다.
- 통전이 끝난(오픈) 상의 로우사이드가 켜진 상태면 BEMF가 그라운드로 클램프되어
  영점검출이 불가능합니다.
- **해결 방법**:
  1. **센서리스 BEMF 방식**: PWM "오프 구간" 동안 오픈 상의 BEMF를 ADC로 샘플링.
     이 구간에는 모든 상이 꺼지므로(또는 오픈 상만) BEMF가 살아 있습니다.
     → 통전 상의 PWM 듀티가 100%가 아니면 매 주기 "off time"이 존재 → 그때 측정.
  2. **저속에서는 오픈 루프(정렬+램프)로 기동**하고, 속도가 올라가면 폐루프 전환.
- 키트의 홀센서 방식(BLCD_Sensored)은 6-step 테이블을 그대로 쓸 수 있지만,
  HDD 모터는 홀센서가 없으므로 **센서리스 경로**를 택합니다.

> 이 프로젝트는 **센서리스 트래피조이달 + PWM 오프 구간 BEMF 샘플링**을 목표로
> 합니다. 다만 첫 단계에서는, 홀센서가 있는 모터나 테스트용 홀센서를 붙여
> 센서드로 먼저 검증한 뒤 센서리스로 옮기는 것을 권장합니다 (docs/09).

## 7.3 센서리스 기동 시퀀스

센서리스 모터는 정지 상태에서 BEMF가 없으므로 반드시 아래 순서를 거칩니다.

### 단계 1: 회전자 정렬 (Alignment)
- 임의의 한 조합(예: A+→B-)을 일정 시간(예: 100~300ms) 유지.
- 회전자가 해당 방향으로 정렬됨. 듀티는 20~30% 정도로 제한.
- 반복 기동 신뢰성을 위해 이전 방향을 기억해 반대로 정렬하는 기법도 있음.

### 단계 2: 오픈 루프 가속 (Open-loop ramp)
- 정렬 후 통전 스텝을 전기각 기준으로 서서히 진행(commutation 주기 감소).
- 가속 기울기와 최소 속도를 정해야 함. 너무 빨리 → 실패, 너무 늦게 → 정지.
- 이 구간 동안 BEMF가 영점검출 가능 크기(수백 mV~1V+)까지 올라갈 때까지 진행.

### 단계 3: 폐루프 전환 (Synchronization / Closed-loop)
- 영점검출 신호와 오픈 루프 시점을 비교해 동기화가 맞으면 폐루프로 전환.
- 전환 직후 전류/토크 스파이크 주의 → 듀티를 낮게 유지.

### 단계 4: 정상 운전 (Closed-loop)
- 영점검출 → 30°(전기각) 지연 → 통전 전환.
- 속도 PI 제어로 듀티 조절 (docs/09).

## 7.4 BEMF 영점검출 (Zero-Crossing Detection)

- 오픈 상의 BEMF가 **가상 중성점 전압(= 버스전압/2 근사)** 과 같아지는 순간을 검출.
- 영점검출 시점은 통전 스텝 경계의 정확히 중간(30°)에서 발생 → 30° 후에
  commutation 수행.
- **측정 방법** (3가지):
  1. 아날로그 비교기(COMP) + 내부 DAC: 하드웨어로 빠르고 간단. F28027 3채널 활용.
  2. ADC 샘플링: PWM 오프 구간에 오픈 상 전압을 샘플 → 펌웨어에서 비교.
     구현이 간단하고 필터링도 쉽지만 CPU 오버헤드.
  3. eQEP/eCAP으로 펄스폭 측정 (주파수 방식).
- HDD 모터처럼 **저인덕턴스·고극수** 모터는 PWM 오프 구간이 매우 짧아 샘플링이
  어려울 수 있으므로, **비교기(방법 1) + 펌웨어 필터** 조합을 권장합니다.

### 가상 중성점 전압
- 센터탭(중성점)이 없는 3핀 모터: 3상 평균 전압으로 근사.
- 통전 중인 두 상과 오픈 상의 전압을 분압해 가상 중성점 생성 회로를 구성.

## 7.5 구현 순서 (빌드 레벨 방식)

controlSUITE 예제의 **빌드 레벨** 방식을 따라 단계별로 검증합니다.
`#define LEVEL` 매크로로 단계 전환.

| 레벨 | 내용 | 검증 포인트 |
|----|----|----|
| **L1** | 전압/전류 센싱만 | ADC로 버스전압·상전류 읽기 |
| **L2** | 오픈 루프 정렬+램프 | 모터가 앞뒤로 갈짓자 운동 → 회전 시도 |
| **L3** | BEMF 영점검출 + 폐루프 전환 | 속도 안정적 회전, 영점검출 인터럽트 동작 |
| **L4** | 속도 PI 폐루프 | 목표 RPM 추종, 부하 변동 대응 |
| **L5** | 보호/FAULT 처리 + SCI 모니터링 | 과전류·과열·과전압 시 안전 정지 |

### 레벨별 파일 구성 (제안)
```
src/
├── main.c              # 초기화 + 메인 루프
├── system_init.c       # 클럭/GPIO/ePWM/ADC 초기화
├── bldc_comm.c         # 6-step 테이블, 상 mux 전환
├── bldc_start.c        # 정렬 + 오픈 루프 램프
├── bemf_zc.c           # 영점검출 (비교기/ADC)
├── speed_ctrl.c        # 속도 측정(eCAP) + PI
├── fault.c             # FAULT/보호 처리
└── sci_monitor.c       # 시리얼 모니터링/명령
```

## 7.6 속도 측정

센서리스에서 속도는 **영점검출 주기** 또는 **commutation 주기**로 계산합니다.

```
전기각 주파수 f_elec [Hz] = 1 / commutation 주기[초]
기계 속도 n [RPM] = (f_elec / P_pair) * 60
```
- P_pair = 극쌍 수 (HDD 모터는 4~6, docs/08에서 측정)
- eCAP(캡처)으로 PWM/영점검출 펄스 주기를 측정하거나, 타이머 카운트로 계산

## 7.7 6-step 통전 방향 (정/역회전)

- 테이블의 스텝 순서를 역순으로 실행하면 역회전.
- HDD 스핀들 모터는 관성(플래터 포함) 때문에 가감속 여유 필요.

## 7.8 보호 기능 (DRV8312 + 펌웨어)

1. **FAULT 핀 감시**: low 감지 시 즉시 3상 PWM 0%, GATE low로 래치 해제 후
   상태 로그, 재시동 시퀀스.
2. **과전류**: 션트 전류를 ADC로 모니터링 → 소프트웨어 리밋.
3. **PWM 주파수**: 10 kHz 이상 유지 (부트스트랩).
4. **통전 직후 스파이크**: commutation 직후 짧은 안정화 시간 후 BEMF 샘플링.
5. **Watchdog**: 제어 루프 hang 방지.
