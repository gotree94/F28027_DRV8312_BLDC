# F28027 + DRV8312 NIDEC HDD BLDC 모터 제어 프로젝트

## 프로젝트 개요

TI의 C2000 계열 MCU인 **TMS320F28027 (Piccolo)** 과 3상 모터 드라이버인 **DRV8312** 를
이용하여 **NIDEC HDD 스핀들용 BLDC 모터**를 구동하고 속도를 제어하는 것을 목표로 하는
프로젝트입니다.

- **MCU** : TI TMS320F28027 (C2000 Piccolo, 60 MHz C28x, 64 KB Flash)
- **드라이버** : TI DRV8312 (3상 인버터 통합, 최대 52.5 V / 6.5 A peak)
- **모터** : NIDEC HDD 스핀들 BLDC (3상, 12 V 정격, 센서리스, 고극수 8~12극)
- **제어 방식** : 센서리스 120° 트래피조이달(trapezoidal) / BEMF 기반(대상 단계) → PI 속도 제어
- **참고 레퍼런스** : TI `DRV8312-C2-KIT` (F28027과 동일 계열 Piccolo를 사용하는 공식 키트)
